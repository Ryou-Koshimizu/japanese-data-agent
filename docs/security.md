# 脅威モデルと公開運用

対象は自分のローカル環境で同梱の架空DBを分析する用途。作者のAPIキーは配布しない。

防御: SELECT AST許可リスト、読み取り専用DB権限、5秒SQL制限、1000行制限、文字列長・履歴長制限、LLMの120秒制限、SQLSTATEのみの修正、型付き出力、秘密情報なしのログ、CSVの数式エスケープ。

残るリスク: 高負荷クエリ、API費用、LLMの誤解説、複雑なSQLやインジェクション、権限のあるDB利用者による外部変更。許可テーブルをビューやユーザー定義関数へ変更しない。データベースの管理者自体を信頼境界の外に置く。

ローカルdevは127.0.0.1のみ。実AIのUI利用にはAGENT_ACCESS_TOKENをサーバーに設定し、閲覧者に共有する。Claudeキーを画面へ入力しない。現時点では1プロセス内の同時実行制限しかなく、分散IPレート制限は未実装。アクセス用トークンとReverse Proxy/Upstashなどの共有ストレージレート制限を併用し、利用上限をAPI事業者側でも設定してから公開する。トークンだけでは十分な乱用対策とはみなさない。
