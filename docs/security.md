# 脅威モデルと公開運用

対象は自分のローカル環境で同梱の架空DBを分析する用途。作者のAPIキーは配布しない。

防御: SELECT AST許可リスト、読み取り専用DB権限、5秒SQL制限、1000行制限、文字列長・履歴長制限、LLMの120秒制限、SQLSTATEのみの修正、型付き出力、秘密情報なしのログ、CSVの数式エスケープ。

運用で見ておく点: 高負荷クエリ（5秒で打ち切り）、API費用（事業者側で上限を設定）、解説文の読み違い（根拠の表とSQLを並べて表示）、DB管理者による変更（管理者は信頼境界の外）。許可テーブルをビューやユーザー定義関数へ置き換えない。

ローカルdevは127.0.0.1のみ。実AIのUI利用にはAGENT_ACCESS_TOKENをサーバーに設定し、閲覧者に共有する。Claudeキーを画面へ入力しない。同時実行の上限は1プロセス単位（2件）。実AIモードをインターネットに公開する構成では、アクセス用トークンに加えてReverse Proxy/Upstashなどの共有ストレージによるレート制限を前段に置き、API事業者側の利用上限も設定する。
