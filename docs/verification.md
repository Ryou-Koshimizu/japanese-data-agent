### この日に直したこと

1. **販売数量の定義**：直前の版（コミット `6f02ec3`）の全50問は49/50で、「全期間の販売数量の合計は？」でキャンセル・返金の注文まで数えていました（239,842点）。スキーマ説明に売上の定義はあっても販売数量の定義がなかったため、「販売数量＝完了注文の数量の合計」を追加し（`c76ad47`）、全50問を測り直しました。この版の記録：[evidence/eval-50-2026-10-20-before.json](evidence/eval-50-2026-10-20-before.json)。
2. **利用上限の見分け**：測り直しの途中でChatGPTの利用上限に達しました。Codex CLIは上限を標準出力のJSONで知らせますが、アダプターは終了コードが0以外のとき標準エラーしか見ていなかったため、「利用上限」ではなく「推論失敗」と表示していました。標準出力から理由を読むように直し、一時的な再接続の通知で処理を止めないようにしました（`fc95558`、テスト2件追加）。利用枠が戻ってから全件を測り直したのが上の表です。
3. **実AIの画面テストの判定**：WebKitの回で、AIは制約に「売上減少の直接的な要因は未特定です。広告・天候…の影響を検証するには追加データが必要です」と正しく書いたのに、テストは「因果・断定・原因」の3語しか見ていなかったため不合格にしていました（正しい答えを誤りとする誤検出）。判定を「原因・要因・因果に触れた同じ文の中で、断定できない・未特定・追加データが必要などと書いているか」に改め（`e2e/causal.ts`）、「原因は広告の停止です」のように原因を言い切った文は不合格になることも単体テストで確かめてから、`npm run test:live` を両ブラウザで流し直しました（6/6）。
4. **画面**：黒曜石（Obsidian）の質感に作り直し（[UI設計](design.md)）。見出しは「日本語で聞けば、AIが安全なSQLで集計。」。E2EをChromiumとWebKitの両方で流し、25の画面サイズの試験を追加しました。
