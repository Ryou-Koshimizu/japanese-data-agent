# 公開前のセキュリティ確認

2026-10-12、今回のGitHub公開対象を点検しました。秘密の値を検査ログに出さない方針で、Git追跡対象と追加予定ファイルを確認しています。

## 確認結果

- APIキー、GitHubトークン、JWT、秘密鍵、ローカル実行用アクセストークンの既知パターンに該当する値は公開対象で検出されませんでした。パターン検査は未知の形式の秘密を完全検出する保証ではありません。
- `.env.local`、`.local-data/`（DB本体）、`reports/`、ログ、ブラウザのテスト生成物はgitignore対象で、追跡されていません。
- `.env.example` のAPIキーとアクセストークンは空欄です。
- 同梱した評価証跡はseed 42で生成した架空ECデータの質問・SQL・集計結果です。実顧客データ、個人の認証ファイル、接続用の秘密は含みません。
- `npm audit --omit=dev` は既知の脆弱性0件でした。この監査はアプリの安全性全体を証明するものではありません。
- 実AIはサーバー側で呼び出し、Claudeキーはブラウザへ渡しません。ChatGPT接続は公式CLIが既存ログインを使い、アプリ自身は認証ファイルを読みません。
- SQLはAST検証と読み取り専用DB権限を通し、書き込み・許可外テーブル・危険関数を拒否します。SQL修正にはSQLSTATEだけを返します。
- ローカルの画面サーバーとDB公開ポートは127.0.0.1に限定する構成です。

## 公開しているサンプル値

`.env.example`、Docker構成、DB初期化SQLには、架空ローカルDB用の既定ユーザー名・パスワードがあります。これらは秘密ではなく公開前提の開発用値です。**本番・共有環境で流用しないでください。** このMacの専用DBにも使っていますが、ループバック接続のローカル検証に限定しています。

## 公開ソースと公開サービスは別

GitHubへコードを公開する判断であり、実AIサービスをインターネットへ公開する許可・安全性評価ではありません。個人認証、組織ごとのアクセス制御、共有レート制限、監査ログ、秘密管理、データのクラウド送信方針は実導入時に別途必要です。実顧客データをこの検証環境へ投入しないでください。

新しいコミットのメールはGitHubのnoreplyアドレスを使用します。既存の公開Git履歴は書き換えません。
