# ADR 002: PostgreSQL ASTとDB権限でSQLを制限する

採用: 2026-10-11。

実PostgreSQLパーサーを使い、SELECT単文、demoスキーマ内の許可テーブル、許可関数・型・演算子に限定する。CTE内の書き込み、SELECT INTO、ロック、再帰、システム表、ユーザー定義関数を拒否する。未知の関数を許可するブラックリスト方式は採用しない。

DBでは専用NOINHERITロール、SELECT権限、READ ONLYトランザクション、5秒タイムアウト、最大1000行のcursor取得を併用する。管理者や書き込み権限の接続は実行時に拒否する。パーサーの検証はDB権限を代替しない。

結果の文字列と会話履歴は未信頼データとしてLLMに渡す。プロンプトだけでインジェクションを完全に防げるとは主張しない。SQL実行側の制約を維持する。

制約: 任意の既存DBへ接続するにはdemoスキーマ・権限・テーブルを合わせる必要がある。ユーザー定義型や関数、再帰分析は意図的に非対応。型付き列の数値表示は最大安全整数内に限定する。
