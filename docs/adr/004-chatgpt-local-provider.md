# 004: ローカルでChatGPTサブスク接続を追加する

2026-10-11。ユーザーの「このMacでChatGPTサブスクのローカルAPIを使ってテストする」という指示を優先する。

## 判断

標準のClaudeアダプターを保持し、`AGENT_PROVIDER=codex` で公式Codex CLIによる推論アダプターを選べるようにする。CLIは既存のChatGPTログインを利用する。非公開エンドポイントの直接呼び出し、認証情報の抽出、独自のトークン転送は実装しない。

画面・HTTP API・DBはローカル、推論はクラウド。ローカルHTTP APIはNext.jsの `/api/analyze`（この分析専用の入口）。

`ModelProvider` の同じインターフェースを使い、CLI・UI・evalから同じSQL生成・検証・読み取り専用実行・最大3修正・解説の処理を使う。

`CODEX_EFFORT=auto` はSQL生成・解説にLow、SQLSTATEを受けた修正にMediumを使うアプリ独自の設定。モデルは `CODEX_MODEL` に固定する。評価を再現できるよう、モデルを隠れて切り替えない。

## 実行境界

一時ディレクトリで `codex exec --ignore-user-config --ignore-rules --ephemeral --sandbox read-only --output-schema ... --json` を起動する。標準のコーディング指示を分析用指示に置き換え、シェル・プラグイン・アプリ・ブラウザ・画像等の機能を無効にする。子プロセスの環境変数はPATH・公式認証に必要なHOME/CODEX_HOME・ロケール・通信設定等に限定する。生成SQLやDB接続をシェル引数に展開しない。質問・履歴・結果は標準入力のJSONデータとして渡す。

完了した構造化応答と実使用量だけを受け入れ、途中・失敗・ツール呼び出しを含む応答は成功扱いにしない。生のCLIエラーや内部推論は画面・ログに出さない。出力1MB、推論115秒の上限を設け、停止時は子プロセス群へ終了シグナルを送り、1秒後に強制終了する。認証ファイルは公式CLIが利用し、アプリ側では読み取り・複製しない。

## トレードオフ

1問ごとにCLIを2回起動して推論する（計画と解説）。所要時間の実測は[検証記録](../verification.md)。サブスクの利用枠を消費し、利用上限に達したときは安全なエラーコードで止まる。Codex CLIのイベント仕様・設定に依存するため、バージョン更新時は `npm run test:live` で実接続を確かめる。

この接続はローカル用途で、公開ホスティングでChatGPT認証を共有する使い方は対象外。Claudeでの正答率は `AGENT_PROVIDER=claude` で同じevalを実行して記録する。
