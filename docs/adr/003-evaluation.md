# ADR 003: SQLの文字列でなく結果を比較する

採用: 2026-10-11。

固定日付2026-10-01、固定seed、固定データで50問のevalを実行する。40問は正解SQLとの結果比較、5問は曖昧さの確認、5問は拒否を採点する。SQLの書き方や列別名が違っても同じ結果は正解とする。数値は相対・絶対許容誤差で比較する。ランキングは順序を保持し、その他は行順を無視する。列の並びは正解と合わせる。

CIのモックテストをLLM正答率として表示しない。実LLM evalは手動CLIのみ。期間・モデル・gitコミット・件数・token・費用単価を成果物に記録し、実行者のキーを使う。単価未設定なら費用はnull。cached inputも通常入力として数えるため、費用は請求額でなく設定単価による保守的推計と明記する。

リスク: 50問は限られたECスキーマ上の回帰セットで、未知DBや自由な質問への一般性能は保証しない。結果がたまたま一致する可能性があるため、カテゴリ別結果と失敗例も保存する。
