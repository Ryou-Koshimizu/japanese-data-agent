# ADR 006: 公開デモで実AIの記録を再生する

## 判断

公開デモ（`AGENT_MODE=demo`）は引き続きAIを呼び出さず、SQLも実行しない。そのうえで、`docs/evidence/` に保存済みの実AI応答（会話評価14ターンと調査デモ1件）を、記録された質問と一致したときだけそのまま返す。結果には `mode: 'replay'` を付け、画面・分析メモ・進捗表示で「実AI記録の再生」と明示する。記録にない質問は従来どおり固定回答を返す。

## 理由

- 審査者の多くはcloneせずにURLで確認する。固定回答だけでは、複数集計・確認・拒否といったハーネスの振る舞いが伝わらない。
- 作者のAPIキーで任意の質問を受ける公開実AIサービスは、費用・乱用・鍵管理のリスクがあり提供しない（ADR 001の方針を維持）。
- 記録はプロバイダー・モデル・ソースSHA-256付きで保存済みで、同じ値を再生するだけなので新しい精度主張を生まない。

## 動作条件

- 再生は記録された質問文の完全一致（空白は無視）で選ぶ。会話の順番は画面の「続きを再生」で記録どおりに案内する。
- 再生結果の「AIが提案した次の調査」は一覧で表示する（実行は実AIモードで行う）。
- 再生中の所要時間・実行回数は記録時の値で、画面にも「記録時」と表示する。
- `tests/replay.test.ts` がシナリオの質問と記録ファイルの一致を検査する。記録を更新したら同時に `src/core/replays.ts` も更新する。
